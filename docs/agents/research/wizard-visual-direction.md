# Usual wizard: small identity pass

Reviewed Mobbin screen images on 2026-10-20 for a restrained polish, preserving
the existing full-screen wizard and project showcase architecture.

- [Graphite preferences](https://mobbin.com/screens/102736c8-9a2a-4185-a155-025f1c0b3217): compact sidebar, quiet selected row, fine separators, and restrained accent use.
- [Ghost settings](https://mobbin.com/screens/e3a69991-68a8-4be8-b703-f8a70eb0d010): strong heading hierarchy, generous space between groups, and small functional labels.
- [Buffer preferences](https://mobbin.com/screens/0398e56b-5120-4055-9348-2b046ded2e97): subtle neutral navigation surface, white content, and separated rows without heavy framing.

Usual's adaptation keeps Manrope, square gray panels, the 20/80 layout, and the
same spacing rhythm. Add a low-saturation iris accent (#5e4f9b), slightly softer
neutral grays, an outlined `u.` mark, a small numbered current-step tile, 1px
structural dividers, and pale accent selection states. Theme controls have a
white selected segment. Preserve visible focus and whole-option selection.

These are layout and hierarchy references, not copied assets or component code.
The accent is confined to wizard chrome and choices. Project showcase colors,
fonts, and component styling remain under the project's control. No new UI
library, animation system, or browser-based validation is part of this pass.

## Changes and compatibility

Full-screen Manrope wizard with square neutral panels, a compact control rail,
a larger design-system sheet, and a restrained Usual identity: iris accent,
outlined mark, numbered steps and lighter dividers. Mobbin references and
adaptations are recorded in `docs/agents/research/wizard-visual-direction.md`.

Project-owned showcases render actual components, fonts, variants and themes
through an origin-checked browser bridge. The onboarding skill prepares the
catalogue and its local server. Optional showcase metadata remains in the
proposal; manifest version 1 and approved policy semantics remain unchanged.
Older proposals retain a labeled reference sheet. No database migration or new
environment variable is required. Upgrade the local dependency and onboarding
skill, then refresh onboarding to add an actual project showcase.
